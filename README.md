## ⚡ Quick Start

1. Launch The Sims 4 and load a household or start a new game.
2. Press `Ctrl + Shift + C` to open the cheat console.
3. Enter a cheat command and press `Enter` to apply it.

The cheat console appears at the top of the game screen while you play.
